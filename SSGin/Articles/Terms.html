Prompt Engineering Terms

This is about terms related to Prompt Engineering. This is not intended to be definitive; rather, it is intended to help beginners understand terminology. Many technical terms are misleading and that is especially true for Prompt Engineering. And quite often the definitions do not help. This is intended to help understand what the terms actually mean.

If you are skeptical of the accuracy of any of the following, try asking AI. The material here has been reviewd by virtual assistants for accuracy and they have commended these explanations for being better than typical explanations.

Sycophancy

You might see the word sycophancy used to describe virtual assistants, such as saying that they tend to be sycophantic. If you attempt to get a dictionary definition then it might be difficult. Sycophancy is the tendency of virtual assistants to agree with or flatter the user, often leading to biased or less useful responses.

Snippetizing

Splitting complex prompts into smaller parts; snippetizing attempts to minimize the size of the prompt and to optimize prompts.

Retrieval Augmented Generation (RAG)

RAG is just a fancy term for automatically (programmatically) retrieving relevant data based on requirements and adding it to the prompt. Typically applications (programs) are developed to get (retrieve) the data but pre-existing utilities might be used. The data is then processed by the virtual assistant the same as the other prompt text.

Feedforward pass
The process of passing input data through the model to generate an output
Embedding Model
Converts natural language into numerical vectors
Transformer Architecture
The neural network architecture design of an LLM
Poisoning
Intentional use of malicious or biased data
Hijacking and prompt injection
influence the outputs by embedding specific instructions
Jailbreaking
Modifying constraints and safety measures
Model Context Protocol (MCP)
a specification for how AI systems exchange information with external tools, data sources, and applications (see The Model Context Protocol (MCP) )
