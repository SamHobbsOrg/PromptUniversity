Prompt Engineering Definition

The term Prompt Engineer is commonly used to refer to someone specializing in communication with AI virtual assistants, often called AI chatbots, typically powered by an instance of a Large Language Model (LLM). An LLM is a type of AI that is trained to understand a very wide range of topics, which is why it is called a large language model.

Many people often use the term LLM to refer to the virtual assistant (such as ChatGPT) itself, but more accurately an LLM is a design for a type of AI, and the virtual assistant is an implementation of that design. The "M" in LLM is for model and a model is a design, not an instance of a model.

A LLM is a type of Natural Language Processing (NLP) model. LLMs are called large because they are trained on vast amounts of data and have a large number of parameters. Smaller NLP models are designed for limited domains (uses).

Also, there are many types of AI and a LLM is just one of multiple possibilities.
